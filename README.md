# ChickenSlaughterML
Machine learning identifies key on-farm welfare indicators to predict slaughter outcomes in slow-growing chickens

A machine learning approach was developed to identify a reduced set of indicators capable of classifying slow-growth chicken flocks according to the outcomes of a complete on-farm welfare assessment, and to evaluate their association with slaughter outcomes
Classification models based on classification and regression trees, k-nearest neighbours, support vector machines, and random forest were compared using repeated resampling (CART, KNN, SVM, Random Forest) were trained and compared. The final model retained six indicators: Best model included cumulative mortality, bedding quality, percentage of lame and featherless birds, and indoor NH₃ and CO₂ concentrations
